# 存储、迁移与批量导入实施计划

## 范围与约定

本次按顺序实现存储安全与保留外链的迁移、SFTP 待导入目录、缩略图及上传体验。复用现有 Rust API、React 后台、图片校验、配额、相册及权限检查。保留已有未提交变更，不操作生产数据库、磁盘挂载或正在运行的服务。

不包含通用 FTP 服务/服务器文件管理器、远程存储驱动、API Token、标签搜索、密码分享、回收站、支付或社交。SFTP 使用宿主机已有工具，应用只读取指定待导入目录，不安装或修改 SSH 服务。

## 1. 存储安全与迁移

- [x] 将自由填写目录升级为已登记的存储列表；新增位置限于部署配置允许的根目录，拒绝符号链接及越界路径。
- [x] 记录存储目录身份，检查目录、挂载/设备变化、可用空间与访问状态；异常时停止对该位置上传，不自动改属主或权限。
- [x] 保留默认存储与历史图片位置，切换默认存储只影响新上传。
- [x] 提供管理员迁移任务：检查容量、逐图复制、SHA256 校验后切换记录，保留 ID、相对路径、日期外链与私有权限。
- [x] 迁移具有持久进度、失败信息、重试和重启恢复；与上传/删除协调，目标冲突不得覆盖。
- [x] 旧副本仅在管理员单独请求清理、且目标校验通过后删除；保留失败现场，不能删除目录中的其他文件。
- [x] 备份明确覆盖边界，提供自定义目录的备份/恢复说明，不能把漏图备份标为成功。

## 2. SFTP 待导入目录

- [x] 部署配置指定独立、只读待导入目录；后台列出候选图片，不允许任意浏览服务器目录。
- [x] 管理员选择归属用户、相册和公开状态（导入默认私有），提交导入任务。
- [x] 复用普通上传的真实图片解码、大小、磁盘、用户状态和配额检查；拒绝符号链接、越界路径及上传中变化的文件。
- [x] 保存逐文件结果与进度，避免任务恢复造成重复入库，支持失败重试；原始导入文件始终保留。
- [x] 文档说明 SFTP 上传到临时文件、完成后改名，再由后台扫描导入。

## 3. 缩略图与上传体验

- [x] 为列表提供按需生成并缓存的缩略图；保持原图字节不变，私有缩略图与原图执行相同访问检查。
- [x] 缓存读写受限，生成并发有界；原图删除时清理相关缓存，原图迁移后缩略图仍可用。
- [x] 图片库使用缩略图，查看/下载/分享继续使用原图地址。
- [x] 支持剪贴板图片、文件夹选择上传，展示队列与逐项结果/进度，只重试失败项。

## 4. 验证与收尾

- [x] 定向单元测试覆盖目录边界、文件身份、复制校验、迁移/导入恢复及缩略图原图保护。
- [x] 扩展隔离 HTTP 测试覆盖管理员授权、私有图、迁移后旧链接、导入配额/去重、缩略图与删除。
- [x] 在普通用户、独占目录中运行 Rust 检查/测试及前端构建和定向断言；需要数据库的验证只在完整隔离条件满足时执行，否则明确记录缺口。
- [x] 更新运维文档和本计划的实际结果，核对差异范围，清理任务进程、缓存、编译产物和临时目录。

## 验收要求

旧链接在切换存储和迁移后仍返回相同原图；迁移不删除未校验的源文件；未授权用户看不到管理数据或私有缩略图；导入不能越过限定目录、用户配额和图片校验；失败任务可继续且不重复创建图片；任何验证不得修改生产权限。
