## 一、核心结论速览

1. **Metronic v9.5.0 能不能作为 PicCove 后台的基础框架？**
   - **完全可以，且天然契合！** 令人哭笑不得的历史真相是：当前仓库 `admin/` 最初其实就是从 `metronic-tailwind-react-starter-kit_v9.5.0.zip` 拷入的（React 19 + Vite 7 + Tailwind CSS v4 + 70 余个 ReUI 组件至今躺在 `admin/src/components/ui/` 里）。
   - **为什么现在这么丑？** 因为 Keenthemes 官方压缩包的 `typescript/vite/` 目录漏打了 `layout-*/components/*` 子组件（完整组件实际在同压缩包的 `typescript/nextjs/` 目录中）。此前 Codex 遇到缺失导入后没有核查同包的 `nextjs` 目录，而是通过修改 `tsconfig.app.json` 屏蔽了全部 39 套 Metronic 布局，转而手写了 **1,743 行复古绿 `.cove-*` 原生 CSS**（`admin/src/piccove/style.css`），并用原生 `<table>`、`<progress>`、`<details>`、`<fieldset>`、`window.confirm` 拼凑页面，还强行锁死了 `forcedTheme="light"` 禁用深色模式，同时在 `admin/public/media/` 留下了 **680 个文件（约 20.9 MiB）** 的无用演示素材随包发布。

2. **为什么页面上到处是“莫名其妙的解释 / 像把代码注释写到了前端”？**
   - 经逐行比对 `admin/src/piccove/*.tsx` 与 `docs/AI-PLAN.md`、`docs/STORAGE-PLAN.md`，此前 Codex 直接把**后端工程规格书里的内部机制、协议要求、锁与去重边界、免责条款**原封不动塞进了前端常驻 `<p>` / `<small>` 标签中（例如在 AI 设置页给用户写 *“上游需支持 Base64 图片输出。模型列表不代表能力检测”*，在移动/编辑/删除/复制处反复念叨五六遍 *“不会改变图片外链 / 公开状态保持不变”*）。

3. **为什么“功能有了但很难用”？**
   - **前后端能力断层**：后端 Rust API 早已实现 `PATCH /api/v1/images/{id}/visibility`（切换公开/私有）和 `?private=true`（私密上传），但前端图库既不能选私密上传，也没有公开/私有开关；甚至用户在 Web 端用 AI 生成图片（默认私有）后点复制链接，页面竟提示 **“这是私有图片，如需公开分享，请先在安卓端设为公开”**！
   - **管理端原始简陋**：无全局仪表盘概览；“全部图片”把用户显示成 `用户 550e8400-e29b-...` 原始 UUID；所有列表均无搜索与多维筛选；无大图灯箱（Lightbox）与右侧详情抽屉（Sheet）；用户表把“审核白名单复选框 + 手动封禁大按钮”直接裸塞进表格行；账号安全页要求先在页面最上方填密码才能点底部的 Passkey 删除按钮。
   - **隐藏性能与逻辑缺陷**：系统设置页用 HTML `hidden` 同时挂载全部 7 个分类面板，导致管理员只要停留在设置页，不可见的面板也在后台每分钟发起近 **40 次轮询请求**；此外还存在**多字节密码改密后在 Web 登录页被 `minLength={12}` 锁死无法登录**、**移动相册覆盖另一端刚改的新文件名**、**`/admin/users` 满页触发 48 次 N+1 数据库查询**等问题。

## 三、实施前待您确认的 4 个小决策

审阅文档后，若整体方向认可，您可以顺便确认以下 4 个偏好（若无特殊指定，我们将按括号内的推荐默认方案执行）：

1. **视觉主色调与深色模式**：是否采用 **Metronic 原生现代中性灰（Zinc）搭配克制的青翠绿/靛蓝品牌点缀，并默认开启浅色 / 深色 / 跟随系统切换**？（推荐：支持浅色/深色/跟随系统，默认浅色，保留图湾清新感但彻底告别老气的全绿背景块）
2. **公开宣传首页 `/` 去留**：当前 `/` 是静态介绍页，登录入口在右上角。重构后是**升级为更精致的现代落地页**，还是希望自用场景下未登录访问 `/` 直接跳精致的 `BrandedLayout` 分栏登录页？（推荐：保留并美化轻量落地页，已登录用户访问 `/` 显示“进入工作台”快捷按钮）
3. **Web 端图片公开/私有能力**：是否按方案在 Web 端正式开放 **“上传时可选公开/私有 + 图库/AI 结果中直接切换公开/私有”**？（推荐：开放，后端接口已完备且经过安全测试，可彻底消灭“去安卓端设为公开”的割裂感）
4. **管理员默认落点**：管理员登录后点击左侧“管理控制台”，默认首项进入新增的 **“全局概览（Dashboard）”** 还是保持原 `/app` 个人图库为登录首屏？（推荐：登录后进 `/app` 个人图库，侧边栏“管理控制台”第一项为 `/app/admin` 全局概览）
