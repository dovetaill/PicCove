## 2026-11-05 Web 使用流程优化（实现与定向验证完成，未部署）

目标：打通创建相册、添加／整理图片、上传和复制分享的完整操作，保留当前视觉组件与既有业务规则。

- [x] 上传队列支持追加，保留失败项及原目标相册；可移除未开始项、停止后续上传；刷新／关闭页面、点击品牌返回首页及退出登录有未完成提示，传输完成与保存成功分开反馈。
- [x] 上传区明确显示目标相册，支持图库非输入区域粘贴；保留格式、大小、公开告知与无效相册拒绝。

- [x] 复制统一为格式选择、单份预览和复制，直链保留快捷入口；私有、待清理及审核限制图片按同一规则跳过并解释；二维码沿用相同分享条件。
