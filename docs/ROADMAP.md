# PicCove 已确认首版范围

## 首版

- [x] 品牌首页、登录／注册、用户工作台、管理员入口。
- [x] 用户名与密码登录、管理员创建用户、用户改密、管理员重置密码。
- [x] 默认关闭的自助注册开关，服务端执行开关与权限校验。
- [x] 用户独立图库、本地原图保存、相册、分页、批量移动／删除。
- [x] 稳定图片 ID 外链、直链／Markdown／HTML 复制。
- [x] 默认 1 GiB 配额与管理员调整、10 MiB 单张限制、磁盘余量保护。
